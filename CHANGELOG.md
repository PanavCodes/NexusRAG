# Changelog

Release notes for NexusRAG are published with GitHub Releases:

https://github.com/NexusRAG/NexusRAG/releases

## Vulnerability Disclosure in Release Notes

When a release fixes a publicly known runtime vulnerability in NexusRAG that already has a CVE or similar public identifier at release time, the release notes identify that vulnerability and summarize the upgrade impact.

If a release has no such vulnerability fixes, the release notes may omit this section.

## Versioning

NexusRAG release tags use semantic versioning, for example `v1.4.3`.
