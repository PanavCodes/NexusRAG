# Project Roadmap & Completed Milestones

### Completed Milestones (NexusRAG v2.0)
- [x] Dual-engine reasoning: Google Gemini + OpenRouter Free tier models.
- [x] Pure cloud embeddings: Google Gemini and OpenRouter.
- [x] Universal office document parsing (Excel `.xlsx`/`.xls`, Word `.docx`, PowerPoint `.pptx`/`.ppt`, RTF, EPUB).
- [x] Full GitHub repository ingestion with shallow clones.
- [x] Secure HTTPS website ingestion with readability article extraction.
- [x] Defense-in-depth security: SSRF guards, archive bomb detection, upload path normalization.
- [x] Automated one-click Windows installers (`setup.bat` and `run.bat`).
- [x] 100% passing test suite across 91 automated tests.
